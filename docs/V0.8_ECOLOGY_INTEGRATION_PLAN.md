# Mutation Meddley v0.8.0 Ecology Integration Plan

## Release thesis

`0.7.0` establishes the first stable playable foundation: every shipped mutation has an immediate baseline, a rank-3 identity, rank-6 specialization, rank-9 capstone or unusual adaptation, controller-usable stances, event-driven verbs, and continuous rank scaling between milestones.

`0.8.0` should **not** primarily add more mutation entries. Its purpose is to make the existing mutation systems participate in the rest of Caves of Qud as ecology rather than as five isolated minigames.

The release thesis is:

> A Mutation Meddley build should change how the player interprets terrain, anatomy, hostile pressure, other mutations, and unusual environmental states. Pair synergies and triads should increasingly alter verbs rather than merely add passive numbers.

The target player experience is that a build such as Hunter Shell + Resonant Crystal + Cinder Gut does not feel like three separate bonuses. It should feel like one organism whose movement, stored states, contact behavior, environment, and weaknesses are entangled.

## Prerequisite freeze

Work on `0.8.0` begins only from a `0.7.x` baseline that has passed normal runtime play without structural failures.

The following `0.7.0` contracts are frozen unless a runtime bug proves they need repair:

- rank 3 / 6 / 9 remain the qualitative evolution milestones
- ranks 2 / 5 / 8 remain maturity increases
- ranks 4 / 7 / 10 remain shared verb-output increases
- the serialized evolution-state envelope remains the persistence mechanism
- existing public persistent fields are not renamed or removed
- the shared bonus-damage recursion guard remains in force
- non-adjacent damage must not spend melee/contact resources
- normal gameplay must remain controller-usable and must not require typing
- dormant `Carapace Evolution` must contribute no tags, pair eligibility, triads, discovery progress, passives, or reactions
- hidden rank-9 adaptations must still be discovered before the rank-9 slot is spent

If a change to one of these rules becomes necessary, it must be treated as an explicit compatibility change rather than being slipped into an ecology feature.

## Primary goals

`0.8.0` has seven primary goals:

1. Convert a curated set of important pair synergies from passive/stat relationships into mechanically visible verb interactions.
2. Convert six flagship triads into true combined loops with coordinated state movement or coordinated spend behavior.
3. Make environmental predicates a first-class, testable subsystem and use them for meaningful world interaction rather than mostly passive resistance.
4. Make body-plan relationships mechanically relevant without taking on unsafe full anatomy rewriting.
5. Make hidden adaptation discovery legible through escalating physiological clues without exposing progress counters.
6. Introduce branch liabilities and opportunity costs so the strongest identities become more specialized rather than universally better.
7. Improve mutation-screen clarity so a player can immediately understand what to do, what is currently primed, what synergies are active, and what constraint is currently limiting the build.

## Explicit non-goals

The following are out of scope for the first `0.8.0` pass unless all core goals are already complete and tested:

- no broad mutation-roster expansion
- no more than two new mutations under any circumstance
- no fourth mandatory evolution menu at rank 10
- no global rewrite of vanilla mutation balance
- no replacement of Qud's body system
- no speculative limb creation/removal API work
- no unverified event APIs
- no Harmony patches merely to make a planned mechanic convenient
- no persistent world-object spam such as leaving permanent clouds, pools, walls, or decals every turn unless a verified Qud API and cleanup lifecycle are established
- no conversion of every one of the 18 triads in a single release
- no attempt to make every recognized pair synergy equally elaborate

`0.8.0` should deepen the existing ecosystem without multiplying the test surface beyond what can realistically be validated.

# 1. Ecology architecture rules

## 1.1 Synergies must have a gameplay verb

A flagship pair or triad is not considered upgraded merely because its passive numbers increased.

Each upgraded relationship must answer all of the following:

- **Eligibility:** what exact mutations/branches must be live?
- **Priming:** what action or environmental condition prepares the effect?
- **State:** what resource, meter, stance, or transient condition represents the preparation?
- **Spend:** what player action or incoming event converts the preparation into an effect?
- **Payoff:** what actually changes in combat, traversal, recovery, positioning, or resource routing?
- **Constraint:** what prevents the effect from being a free always-on multiplier?
- **Feedback:** what message or mutation readout tells the player that the interaction occurred?
- **Scaling:** which owning mutation's `Level` controls the magnitude?
- **Failure behavior:** what happens if the target disappears, the event is non-contact, the environment changes, or the effect is cancelled?

If these questions cannot be answered, the relationship remains a passive synergy and is not counted toward the `0.8.0` flagship quota.

## 1.2 Mutation-local ownership remains mandatory

Pair and triad logic remains owned by the mutation class applying the effect.

A triad may have multiple mutation-local slices, but those slices should now coordinate around a shared concept rather than independently stacking unrelated AV/DV/Quickness.

No global synergy manager should directly mutate all five mutations' internal state unless there is a compelling need. The preferred model is:

- shared framework answers semantic/eligibility questions
- each participating mutation reads the relevant relationship
- each mutation changes only its own resource or effect
- messages and readouts make the combined result legible

This keeps save ownership, unmutation behavior, and regression debugging local.

## 1.3 Existing state should be reused before new meters are added

`0.8.0` should not create a new named meter for every synergy.

Prefer transformations among existing resources:

- Carapace: Brace, Impact, Heat/Mire/Rime attunement
- Living Crystal: Stress, Dawn, Dusk, Cadence, Release
- Brineborn: Reserve, Mend, Bastion, Wake
- Ash Metabolism: Embers, Kiln, Rush, Haze
- Walking Colony: Colony Pressure, Stitch, Scout, Parliament

A new persistent state key is justified only when the interaction cannot be expressed coherently by changing generation, retention, conversion, refund, targeting, or spend rules of these resources.

## 1.4 Synergy magnitude follows the effect owner

If Living Crystal performs an electrical crystal discharge, Living Crystal's `Level` controls Mutation Meddley continuous verb scaling for that discharge.

If Brineborn converts electrical pressure into a Reserve hazard, Brineborn owns and scales its local contribution.

Do not average mutation levels or multiply level-derived outputs together. That would create severe runaway scaling in high-investment multi-mutation builds.

## 1.5 Cross-mutation proc recursion remains suppressed

Synthetic Mutation Meddley bonus damage must not recursively create another Mutation Meddley synthetic proc chain.

A normal player attack may satisfy multiple top-level owned mutation handlers if explicitly intended, but synthetic follow-up damage must remain inside the shared recursion guard.

Triad design must therefore prefer coordinated resource conversion before/after the normal attack rather than depending on synthetic damage recursively triggering another participant.

## 1.6 No guessed Qud API

Every new Qud-specific mechanic must be verified against at least one of:

- the user's installed Qud assemblies / generated `Mods.csproj`
- current official Qud modding documentation
- current base-game source symbols exposed to scripting mods
- a controlled DEV trace proving the event/parameter semantics in the target game version

If exact API semantics are unknown, write the desired behavior in the plan and instrument it first. Do not invent a method, event field, damage type, body API, liquid API, effect API, or targeting API.

# 2. Flagship pair synergy conversion

The first `0.8.0` pass should convert **twelve** curated pair relationships into visible verbs. The selection intentionally covers all five Mutation Meddley families and several important vanilla mutations.

Passive bonuses may remain as secondary support, but the relationship is considered complete only when the verb interaction is live.

## Pair 1 — Carapace Evolution + Quills: Integrated Thorn Frame

### Eligible branches

- Fortress
- Hunter Shell

Adaptive Carapace should not automatically gain the same quill behavior; keeping the relationship branch-sensitive prevents Quills from being universally optimal.

### Fortress behavior

- Holding ground with Brace primes the shell/quill interface.
- A qualifying incoming adjacent melee hit may spend or reference Brace to produce a quill-backed retaliation.
- `Spiteful Wall` should emphasize immediate retaliation.
- `Anchor Down` should emphasize Brace retention or retaliation efficiency.
- `Porcupine Redoubt` remains the highest expression and should improve this exact loop rather than append a separate proc.

### Hunter behavior

- Moving melee contact with Impact can use quills as hooking surfaces.
- `Ramming Gait` should favor a stronger contact follow-up.
- `Skirmish Gait` should favor an Impact refund or pursuit retention instead of equivalent damage.
- `Hookstorm Frame` should be the capstone expression of this relationship.

### Constraint

The quill effect must require real Brace/Impact context; possession of Quills alone must not grant free damage every hit.

### Acceptance test

The player can remove Quills and immediately observe that the extra shell/quill behavior disappears while base Fortress/Hunter behavior remains intact.

## Pair 2 — Carapace Evolution + Multiple Legs: Articulated Pursuit Shell

### Eligible branches

- Hunter Shell primarily
- Adaptive Carapace secondarily only if a verified traversal interaction is useful

### Planned verb

- Consecutive movement should improve Impact retention rather than simply add permanent speed.
- Successful adjacent melee contact after movement can refund part of the Impact spent.
- `Ravager Joints` and `Skitter Bulwark` should specialize this interaction.
- Breaking pursuit by remaining stationary should rapidly remove the special benefit.

### Constraint

The interaction must reward actual movement/contact sequencing. Extra legs must not simply create a permanent Hunter damage multiplier.

## Pair 3 — Living Crystal + Electrical Generation: Conductive Lattice

### Eligible branches

- Diamond Lattice
- Resonant Crystal
- Prismatic Matrix may receive a smaller optical/conductive interaction only if it remains distinct

### Diamond behavior

- Stress may act as a temporary electrical sink.
- A qualifying Stress spend can add an electrical-themed synthetic follow-up only if a verified way to represent that damage safely exists.
- If damage typing cannot be verified, the first implementation should remain generic bonus damage with conductive messaging and a documented TODO rather than inventing electrical damage APIs.

### Resonant behavior

- High Cadence/Release can synchronize with Electrical Generation.
- Spending Release may refund a small amount of Cadence or accelerate the next Release threshold.

### Constraint / liability

Conductive Crystal should also create risk under actual electrical pressure if a verified incoming electrical-damage signal exists. If damage-type detection cannot be verified, defer the liability rather than faking it.

## Pair 4 — Living Crystal + Light Manipulation: Deliberate Refraction

### Eligible branch

- Prismatic Matrix

### Planned verb

- Light Manipulation should let the Prismatic build deliberately stabilize Dawn in lit conditions and preserve or sharpen a Dawn discharge.
- `Sunlens Array` / `Solar Wake` should improve movement-through-light behavior.
- The interaction should affect Dawn generation, retention, or discharge rather than merely provide another DV line.

### Constraint

The bonus must depend on actual lit-state checks and Prismatic state. It cannot be a permanent reward for simply owning Light Manipulation.

## Pair 5 — Living Crystal + Phasing: Phase Refraction

### Eligible branch

- Prismatic Matrix -> Shade Reflector

### Planned verb

- Dimness plus phase-compatible biology should preserve Dusk through a pressure event or change how a Dusk discharge is spent.
- `Null Prism` should be the mature expression of the mechanic.

### Constraint

The effect should require dim state and the correct branch. Do not attempt to control Qud's actual Phasing activation/cooldown unless a verified API makes that safe.

## Pair 6 — Brineborn + Electrical Generation: Conductive Brine

### Eligible branches

- Saltglass Bloom
- Scouring Estuary
- Wellspring Flesh receives only a defensive interaction if justified

### Planned verb

- Saline Reserve should become a meaningful conductivity resource.
- Scouring can convert conductive Reserve into a sharper Wake contact payoff.
- Saltglass can convert conductivity into a brittle Bastion retaliation.

### Required liability

This relationship must not be purely positive. If verified damage typing is available, high Reserve should increase the danger of incoming electrical damage or consume Reserve defensively when electrical pressure arrives.

If electrical damage identification is not safely available in the target Qud API, ship the positive interaction only after documenting the missing liability as blocked; do not invent type detection.

## Pair 7 — Brineborn + Regeneration: Tidal Recovery Circuit

### Eligible branch

- Wellspring Flesh

### Planned verb

- Regeneration should change **when** Reserve/Mend is recovered, not merely increase healing numbers.
- A successful Mend spend can recycle a small amount of Reserve or accelerate the next Mend bank.
- `Tidal Marrows` and `Undertow Heart` should deepen the cycle.

### Constraint

The loop must still consume Reserve or Mend. Regeneration cannot create infinite free healing while standing safely out of combat.

## Pair 8 — Brineborn + Amphibious: Native Estuary

### Eligible branches

- Wellspring Flesh
- Scouring Estuary
- Adaptive Carapace interactions remain handled on the Carapace side

### Planned verb

- Wet traversal should reduce Reserve decay or convert movement into a small Reserve/Wake retention effect.
- Scouring should become more fluid when crossing qualifying wet terrain.
- Wellspring should bank environmental sustain more efficiently in wet spaces.

### Constraint

The relationship should make wet terrain strategically valuable without making dry terrain irrelevant.

## Pair 9 — Ash Metabolism + Freezing Ray: Thermal Shock

### Eligible branches

- Furnace Skin
- Cinder Gut

### Planned verb

- Alternating between strong heat ecology and cryogenic capability should create a **thermal-shock conversion** inside existing Kiln/Rush resources.
- Furnace can turn a hot Kiln state plus cryogenic interaction into a brittle retaliation or forced Kiln spend.
- Cinder can trade part of Rush/Embers for a stronger next contact after a temperature reversal.

### Constraint / liability

Cold should meaningfully disrupt an Ash build when it is not deliberately using the Freezing Ray synergy. The synergy is valuable because it learns to exploit a normal weakness, not because cold becomes universally beneficial.

### API note

Do not attempt to intercept Freezing Ray internals until the current target API is verified. If direct activation detection is unavailable, use verified environmental/cold-damage events or defer the exact trigger.

## Pair 10 — Ash Metabolism + Flaming Ray: Combustion Feed

### Eligible branches

- Furnace Skin
- Cinder Gut

### Planned verb

- Verified use of Flaming Ray or verified resulting heat state should improve Ember/Kiln/Rush routing.
- Furnace should bank heat more effectively.
- Cinder should be able to convert fresh combustion into pursuit fuel.

### Constraint

This cannot become free Embers every turn merely because Flaming Ray exists on the character. There must be an actual trigger or environmental consequence.

## Pair 11 — Walking Colony + Multiple Legs: Distributed Locomotion

### Eligible branch

- Surveyor Swarm

### Planned verb

- Consecutive movement should generate Scout more efficiently or preserve Scout after a successful chase spend.
- `Latch Runners`, `Pack Pursuit`, and movement-based unusual adaptations should deepen the same routing loop.

### Constraint

Standing still breaks the special locomotion bonus. Multiple Legs should reward a mobile colony, not every Walking Colony identity.

## Pair 12 — Walking Colony + Burrowing Claws: Subsurface Labor

### Eligible branches

- Marrow Hive
- Surveyor Swarm

### Marrow behavior

- Rooted/stationary pressure with Burrowing Claws can improve Stitch generation or retention.
- `Bone Nursery` and `Burrowed Nursery` should deepen this exact relationship.

### Surveyor behavior

- Hostile-terrain traversal can become more valuable if Burrowing Claws is present, provided the terrain predicate is verified.

### Constraint

No automatic map excavation or body-part editing in this pass. The interaction is about labor/routing state unless a verified Qud API later justifies more.

# 3. Six flagship triads

Only six triads receive full combined-verb treatment in `0.8.0`. The other twelve remain valid named relationships and may keep their existing passive slices until a later pass.

The six selected triads cover different playstyles and all five mutation families.

## Triad 1 — Cathedral Organism

**Required:** Fortress + Diamond Lattice + Saltglass Bloom.

### Identity

A stationary layered fortification whose shell, crystal stress, and saline mineralization pass force through one another.

### Combined loop

1. Holding position builds Brace and Diamond Stress.
2. Saline conditions or Saltglass state reinforce the structure through Reserve/Bastion.
3. Incoming adjacent pressure should consume the resources in a predictable order rather than causing three unrelated procs.
4. One participant performs the direct retaliation while the others refund, preserve, or transform their own state.

### Preferred coordination

- Carapace owns the immediate held-line reaction.
- Living Crystal may convert surviving Brace/Bastion pressure into Stress retention or discharge.
- Brineborn may preserve Bastion or return a small Reserve amount after a successful structural exchange.

### Constraint

Moving should disrupt the cathedral state quickly. This triad must be excellent at holding a line and poor at chasing.

## Triad 2 — Ember Pursuit Engine

**Required:** Hunter Shell + Resonant Crystal + Cinder Gut.

### Identity

Movement produces three related forms of momentum that resolve into one coordinated pursuit strike.

### Combined loop

1. Movement builds Impact, Cadence/Release, and Rush under their normal rules.
2. A qualifying adjacent melee contact chooses a coordinated spend order.
3. The first participant provides direct bonus damage.
4. The other participants convert successful contact into partial meter retention/refund rather than each firing a full extra damage proc.
5. Continued movement keeps the engine alive; standing still causes rapid collapse.

### Constraint

This triad should be powerful only while maintaining pursuit. It must not become a stationary boss-killing multiplier.

## Triad 3 — Steam Choir

**Required:** Scouring Estuary + Resonant Crystal + Smoke Organ.

### Identity

Wet movement, atmosphere, and resonance create a mobile obscuring pressure ecology.

### Combined loop

1. Wet traversal and smoky conditions prime the triad.
2. Brineborn improves Wake routing.
3. Living Crystal improves Release/Cadence retention in the primed environment.
4. Ash converts the same environment into Haze retention or a movement-defense response.
5. The triad should feel strongest while crossing wet/smoky contested ground.

### Environment requirement

Do not create literal steam clouds until a verified, performant Qud gas/liquid API and cleanup model exist. The `0.8.0` version may represent Steam Choir entirely through state routing and combat effects.

## Triad 4 — Ossuary Rampart

**Required:** Fortress + Marrow Hive + Diamond Lattice.

### Identity

A biological anti-burst wall: shell holds force, crystal distributes it, colony repairs the aftermath.

### Combined loop

1. Stationary play builds Brace/Stress while Colony Pressure or Stitch remains available.
2. A heavy incoming exchange consumes one defensive resource.
3. Surviving the exchange helps another participant preserve or regenerate its resource.
4. Colony healing should occur after the structural participants absorb the exchange, not simultaneously as three separate heal events.

### Constraint

Mobility should be poor. If the player moves repeatedly, the triad should lose most of its coordinated benefit.

## Triad 5 — Undertow Furnace

**Required:** Wellspring Flesh + Cinder Gut + Marrow Hive.

### Identity

A recovery engine that metabolizes hostile heat and wet conditions into repeated but resource-limited survival.

### Combined loop

1. Brine Reserve/Mend is the central recovery resource.
2. Ash heat/Embers influence how quickly the cycle can be re-primed.
3. Colony Pressure/Stitch determines whether the body can sustain repeated exchanges.
4. A successful recovery event should shift resources between these systems rather than simply triple-heal.

### Constraint

The loop must have depletion. It should be extremely durable under the right ecology, but dry/calm/no-resource conditions must eventually shut it down.

## Triad 6 — Chorus Husk

**Required:** Resonant Crystal + Graft Parliament + Adaptive Carapace.

### Identity

A distributed body that treats resonance, attunement, and delegated strain as one unstable frame.

### Combined loop

1. Adaptive Carapace chooses or accumulates environmental attunement.
2. Resonant movement/stillness determines Cadence/Release.
3. Graft Parliament stores delegated load.
4. Pressure can shift one unit of state among these systems according to stance/environment rather than independently triggering three reactions.
5. The build should feel strange and flexible, but less numerically efficient than a pure fortress or pure pursuit triad.

### Constraint

The player must actively retune stances and respond to environment. The triad should not collapse into a permanent all-purpose defense package.

# 4. Environmental integration subsystem

## 4.1 Centralize environment predicates

`0.8.0` should formalize the existing environment checks into a clearly documented sensor layer.

Minimum sensor set:

- `lit`
- `wet`
- `saline`
- `hot`
- `smoky`
- `hostileTraversal` derived only from verified constituent states

For each sensor, document:

- authoritative API, if one exists
- fallback heuristic, if one remains necessary
- known false positives
- known false negatives
- representative test cells
- which mutations depend on it

`Cell.IsLit()` can remain the authoritative light source where current target behavior supports it.

Wet/saline/hot/smoky detection should be upgraded only through verified APIs. If a heuristic remains necessary, it must remain visible in DEV diagnostics instead of being presented as guaranteed world truth.

## 4.2 Environment provenance in DEV mode

`Evolution Seed [DEV]` should eventually show not only boolean state but enough diagnostic context to determine why a sensor fired.

Desired DEV readout concept:

- lit = true (Cell.IsLit)
- wet = true (open liquid volume)
- saline = true (liquid/terrain classification)
- hot = false
- smoky = true (matched verified gas or fallback heuristic)

Exact formatting can change, but runtime debugging must make heuristic mistakes reproducible.

## 4.3 World-interaction principles by mutation

### Carapace Evolution

- Adaptive Carapace should care most about environmental transitions.
- Moving from one environment class to another can change attunement generation/retention.
- Fortress and Hunter should receive only narrow environmental interactions so Adaptive retains identity.

### Living Crystal

- Prismatic remains the main light-space identity.
- Diamond should care more about pressure/held geometry than about arbitrary terrain buffs.
- Resonant should care about movement rhythm and, only where verified, sound/resonance-friendly context.

### Brineborn

- Wet/saline terrain should determine Reserve opportunity and risk.
- Dry terrain should remain a real resource problem for some branches.
- Electricity and temperature should be the main cross-system environmental risks once verifiable.

### Ash Metabolism

- Hot and smoky states should matter as actual fuel/route conditions.
- Cold should be a meaningful disruption unless a branch/synergy learns to exploit thermal shock.
- Smoke Organ should get the strongest atmosphere-specific routing behavior.

### Walking Colony

- Surveyor should get the strongest traversal history value.
- Marrow should care about recovery windows and rooted terrain use.
- Parliament should care about body-plan strain more than generic environment.

## 4.4 Avoid permanent world spam

The first world-integration pass should favor:

- state conversion
- resource generation/decay
- temporary actor effects
- target-local bonus damage
- movement-conditioned refunds
- verified cell/environment queries

Avoid spawning persistent environmental objects until lifecycle, cleanup, save behavior, and performance are proven.

# 5. Body-plan integration

## 5.1 Scope

`0.8.0` should make anatomy relevant without rewriting Qud's body system.

Allowed first-pass interactions:

- detect possession of known mutations such as Multiple Legs, Quills, Burrowing Claws, vanilla Carapace, Amphibious
- use existing semantic tags such as `STRUCTURAL`, `BODY_PART_INTERACTION`, `MOBILE`, and `CHITINOUS`
- change resource generation/retention/spend based on those relationships
- change mutation-local combat verbs based on those relationships

Deferred unless verified and demonstrably save-safe:

- adding/removing limbs
- changing body slots
- replacing body parts
- mutating equipped items through anatomy changes
- directly editing body-plan XML at runtime

## 5.2 Graft Parliament becomes the body-plan benchmark

Graft Parliament should become the mutation that most clearly rewards unusual anatomy.

Planned rules:

- `Delegate Load` benefits from other live `BODY_PART_INTERACTION` anatomy by banking Parliament more efficiently.
- `Override Frame` benefits from live `STRUCTURAL` anatomy by converting movement/pressure into Parliament more aggressively.
- Multiple Legs, Quills, Burrowing Claws, and live Carapace relationships should not all do the same thing.
- rank-6 choices must determine whether the player prefers calm redistribution or active exploitation.
- `Colony Interface`, `Molt Parliament`, and `Choir of Tendons` remain deeper expressions of those relationships.

## 5.3 Body-plan synergy must remain optional

No base mutation may require another anatomy mutation to function.

The `0.6.3` solo-Graft fallback remains mandatory. Body-plan synergies make a functioning loop stranger or more efficient; they do not unlock its basic existence.

# 6. Hidden adaptation discovery UX

The hidden-adaptation system should remain genuinely hidden, but discovery should no longer be silent until the final unlock.

## 6.1 Three-stage clue model

Each unusual adaptation should support three player-facing moments:

1. **First omen:** the build has begun satisfying the hidden pattern.
2. **Deepening omen:** repeated behavior indicates the body is learning something unusual.
3. **Discovery:** the unusual adaptation is permanently revealed for the still-unspent rank-9 slot.

No numeric progress such as `3/5` should be shown in normal gameplay.

DEV mode may continue to expose exact progress for debugging.

## 6.2 Clue persistence

Clue thresholds should use the existing serialized state envelope.

Do not add new public fields solely for clue messages.

Each threshold should be one-shot so repeated qualifying turns do not spam the message log.

## 6.3 Planned clue tone by adaptation

The exact prose can be revised during implementation, but each hidden adaptation should have a clear sensory theme.

### Living Crystal

- **Fractured Choir:** faint internal harmonics -> fractures begin answering footsteps -> the lattice learns to sing through damage.
- **Heat Sink Choir:** facets hold impossible thermal afterimages -> heat stops leaving cleanly -> thermal shock resolves into a new choir geometry.
- **Solar Wake:** bright movement leaves persistent glare-lines -> facets begin pulling light behind the body -> the wake becomes an evolution option.
- **Null Prism:** shadows appear to pass through the lattice -> dimness leaves brittle gaps in reflection -> absence itself becomes selectable geometry.

### Brineborn

- **Salt Ghost:** brine seems to remember where the body was -> saline movement leaves phase-like afterimages -> salt becomes a phase anchor.
- **Brine Reliquary:** stationary salt deposits stop flaking normally -> mineral memory thickens around repeated positions -> reserve learns to become a reliquary.
- **Undertow Heart:** recovery pulses begin arriving out of rhythm -> healed tissue seems to pull the next brine pulse forward -> the heart discovers undertow timing.
- **Abyssal Brine:** cold reserve settles deeper than normal -> wet cold stops behaving like surface weather -> the body discovers abyssal stillness.

### Carapace Evolution

- **Porcupine Redoubt:** quills begin seating into shell seams -> rooted pressure aligns quills into defensive geometry -> the shell discovers the redoubt.
- **Estuary Husk:** wet shell seams stop drying normally -> saline films persist beneath plates -> the shell begins breathing as a membrane.
- **Skitter Bulwark:** articulated segments begin anticipating extra-leg movement -> pursuit feels increasingly wall-like -> the shell discovers moving fortification.
- **Hookstorm Frame:** quills catch during committed contact -> repeated rams leave the shell bristling forward -> the frame discovers hookstorm geometry.

### Ash Metabolism

- **Volcanic Memory:** hot structure retains an afterimage of pressure -> cooled tissue still remembers heat lines -> structure becomes stored eruption.
- **Wake Eater:** the body starts reacting to recently traversed heat -> pursuit seems to feed on what was just left behind -> heat wake becomes edible.
- **Cenotaph Haze:** smoke lingers perceptually after leaving the cell -> the body begins occupying a false atmospheric outline -> haze becomes a temporary ecology.
- **Cinder Jet:** moving smoke starts pulling behind the body -> draft pressure becomes directional -> the lungs discover a predatory jet.

### Walking Colony

- **Burrowed Nursery:** stationary colonies settle toward the claws -> buried pressure starts returning as repair -> the nursery learns subterranean labor.
- **Wake Trail:** scouts begin favoring recently hostile routes -> movement history becomes a persistent hunting pattern -> the colony discovers the trail.
- **Molt Parliament:** structural burden begins feeling negotiable rather than damaged -> the colony reallocates labor around worn anatomy -> the parliament learns to molt.
- **Choir of Tendons:** stationary strain develops rhythmic coordination -> vibration begins redistributing load -> the colony discovers a tendon choir.

## 6.4 Discovery remains missable

The player should still be able to reach rank 9 without discovering an unusual adaptation.

Clues communicate possibility; they do not guarantee success or reveal the exact recipe.

# 7. Branch liabilities and specialization costs

`0.8.0` should introduce liabilities primarily as **resource or positional constraints**, not as arbitrary permanent negative stats.

A liability is successful when it makes the player change behavior.

## 7.1 Carapace Evolution

### Fortress

- Brace should decay faster after repeated movement.
- Strongest retaliation should require remaining planted.
- The branch gives up pursuit flexibility.

### Hunter Shell

- Impact should decay rapidly during stationary turns.
- Strongest contact behavior requires recent movement.
- The branch gives up reliable held-line defense.

### Adaptive Carapace

- Attunements should compete or decay when the environment changes.
- The player cannot remain maximally tuned to every climate indefinitely.

## 7.2 Living Crystal

### Diamond Lattice

- Stress is strongest when accepting pressure/holding position.
- Movement should make maintaining peak structural state less efficient.

### Prismatic Matrix

- Dawn and Dusk should favor different environments and should not both remain maximized effortlessly.
- Moving between light regimes should create an actual retuning decision.

### Resonant Crystal

- Cadence/Release should punish broken rhythm.
- Standing still after a mobile buildup is useful only on the branch designed to convert that rhythm into guarded output.

## 7.3 Brineborn

### Wellspring Flesh

- Dry conditions should remain a Reserve problem.
- Sustain must eventually stop when Reserve/Mend is exhausted.

### Saltglass Bloom

- Rooted shell and moving edge styles should compete rather than stack freely.
- Switching stance should change which resource conversion is efficient.

### Scouring Estuary

- Stationary play should rapidly lose Wake value.
- Strong dry-country pressure requires consuming stored ecology.

## 7.4 Ash Metabolism

### Furnace Skin

- Cold or lack of heat should make Kiln maintenance difficult.
- Furnace is strongest when accepting environmental commitment.

### Cinder Gut

- Rush should fall quickly when pursuit stops.
- Strong offense requires continued motion and Ember consumption.

### Smoke Organ

- Clear air should erode Haze more aggressively than smoky environments.
- The branch should be weaker in open clean conditions and stronger when atmosphere can be exploited.

## 7.5 Walking Colony

### Marrow Hive

- Active movement should compete with the deepest Stitch banking.
- Best sustain requires recovery windows rather than permanent mobile healing.

### Surveyor Swarm

- Staying inert should collapse Scout advantage quickly.
- Repeated movement is the cost of maintaining route pressure.

### Graft Parliament

- High delegated load should represent burden as well as power.
- The first implementation should prefer slower resource decay, conditional spend inefficiency, or stance tension over a blunt permanent stat penalty.

# 8. Player-facing mutation information

The mutation screen must remain readable despite the added ecology.

## 8.1 Information hierarchy

Every Mutation Meddley mutation should answer these questions in this order:

1. **What am I?** Current lineage: rank-3 identity -> rank-6 specialization -> rank-9 capstone/unusual adaptation.
2. **What should I do?** One concise operating instruction based on the current branch and stance.
3. **What am I storing?** Current primary resource(s) and cap.
4. **What is primed right now?** Examples: adjacent-contact spend ready, saline Reserve active, hot/smoky ecology active.
5. **What synergies are changing my loop?** Show active flagship pair/triad names and one-line effect summaries.
6. **What is constraining me?** Show the branch liability when it is currently relevant.
7. **What will my next mutation rank improve?** Preserve the `0.7.0` continuous-growth summary.

## 8.2 Active versus eligible language

Use distinct wording:

- **Eligible:** the character has the required mutations/branches.
- **Active:** the current stance/environment/state satisfies the gameplay condition.
- **Primed:** the resource is ready to be spent on the next qualifying event.
- **Dormant:** a required parent system is absent, especially Carapace Evolution without vanilla Carapace.
- **Unusual adaptation discovered:** permanently available at rank 9 while the tier remains unspent.

Do not call a synergy active merely because its ingredients exist if its actual environmental or resource gate is not currently satisfied.

## 8.3 Controller UX

If the normal mutation description becomes too dense, add a controller-friendly inspection popup rather than requiring keyboard commands or typed debug input.

Any new inspection ability must:

- work with controller/Steam Deck
- use option-list style navigation or the current verified replacement API
- consume no combat energy if it is purely informational
- not alter state
- not expose hidden recipes unless DEV mode is active

# 11. Performance budget

`0.8.0` adds many more conditional interactions, so hot-path discipline matters.

Rules:

- no reflection in combat or turn handlers
- no global world-object scans per turn
- no repeated full mutation-list scanning when one cached/semantic query is sufficient
- no uncontrolled per-turn string construction outside player-facing diagnostics
- no persistent environmental object creation without cleanup/performance proof
- synthetic damage remains guarded
- message output should be event-significant, not every-turn meter chatter
- DEV tracing remains opt-in

Stress test target:

- character with all five Mutation Meddley gameplay mutations active
- multiple recognized vanilla synergy mutations
- continuous movement through at least 200 cells
- repeated melee exchanges
- environmental transitions
- save/reload mid-run

The release is blocked by reproducible stutter attributable to Mutation Meddley event processing.

# 12. Save compatibility rules

The existing evolution-state envelope remains the preferred storage location for any new progress markers.

Rules:

- do not rename existing state keys
- do not remove existing state keys simply because a mechanic changes
- new clue thresholds may add new envelope keys
- active pair/triad eligibility remains derived, not serialized
- environmental state remains derived, not serialized

If a new state key changes the meaning of an old key, add explicit compatibility handling rather than silently reinterpreting persisted values.

# 13. Regression matrix

Every `0.8.0` release candidate must re-run the `0.7.0` contracts in addition to new ecology tests.

## Core progression

For each mutation:

- rank 1 baseline works
- rank 2 maturity is visible
- rank 3 identity works
- rank 4 verb growth works
- rank 5 maturity works
- rank 6 specialization retains prior growth
- rank 7 verb growth works
- rank 8 maturity works
- rank 9 capstone/unusual adaptation retains prior growth
- rank 10 growth works

## Contact safety

- adjacent melee contact may spend contact meters
- non-adjacent ranged damage does not spend contact meters
- synthetic bonus damage does not recursively proc Mutation Meddley synthetic damage
- failed target resolution does not silently destroy stored resources unless explicitly designed

## Stances

- both stances remain mechanically meaningful on every rank-3 identity
- retuning does not duplicate continuous-passive bonuses
- retuning does not reset hidden progress or meters unless explicitly documented

## Pair synergies

For each of the twelve flagship pairs:

- absent ingredient -> no pair verb
- wrong branch -> no pair verb
- correct branch, unprimed -> no payoff
- correct branch, primed -> exactly intended payoff
- partner mutation removed -> effect disappears safely
- save/reload -> active eligibility recomputes correctly

## Triads

For each of the six flagship triads:

- two-of-three never produces the full triad verb
- wrong branch never produces the full triad verb
- all three correct but unprimed remains dormant/eligible only
- fully primed produces one coordinated exchange rather than uncontrolled proc stacking

## Hidden adaptations

All 20:

- clues occur once at intended thresholds
- no exact recipe/progress in normal mode
- discovery persists
- discovery stops after tier 3 is spent
- selected unusual adaptations still behave after save/reload

## Dormancy

Carapace Evolution:

- losing vanilla Carapace suppresses continuous scaling, pair verbs, triad slices, clues, and reactions
- state is retained
- regaining vanilla Carapace reactivates the previous configuration without duplicate ability registration

# 17. Definition of success

`0.8.0` succeeds if players stop describing Mutation Meddley builds as a list of separate mutations and start describing them as organisms.

A successful player description should sound like:

- "I hold saline chokepoints because my Fortress, Diamond lattice, and Saltglass state feed one another."
- "I have to keep moving because Impact, Cadence, and Rush all collapse if I lose pursuit."
- "Cold normally disrupts my Ash build, but I deliberately use thermal shock because I built around Freezing Ray."
- "My colony uses my extra legs differently from my claws; those anatomy choices change the loop, not just the stats."
- "I knew something strange was happening to my shell before Porcupine Redoubt finally appeared, but the game never gave me a checklist."

That is the `0.8.0` target: fewer isolated bonuses, more ecology, more player-readable causality, stronger tradeoffs, and more reasons for Qud's world and mutation combinations to matter.
